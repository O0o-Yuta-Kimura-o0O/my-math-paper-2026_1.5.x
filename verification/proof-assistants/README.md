## 収録した定理（各ファイル 25）

- fだけの木 `F`、自由な構成子型の自然数 `N` と有限列、本文§10.2 の六つの信頼する規則。
- §10.2 の16命題：加法の左零・左後続・可換・結合・四項交換、乗法の左零・右単位・左後続・可換・左単位・二つの分配・結合、有限列の連結の左単位・右単位・結合。
- 定理10.4（規則による値の一意性）の、加法・乗法・連結の場合と、加法が規則で決まること。
- 自然数をfの鎖として表す符号化の往復（`dec (enc n) = some n`）。
- 二進の表示の後者と加法が復号と両立すること、二進の加法が加法を規則どおりに計算すること（命題10.6、系10.5 の形の主張）。

## 再現手順

```sh
lean FGen.lean
rocq compile FGen.v
agda --ignore-interfaces FGen.agda
```

検査が規則の中身に依存していることは、二つの壊した写し（`add.succ` の右辺から `S` を除いたもの、二進の加法から繰り上がりを除いたもの）が三つの系すべてで拒否されることで確かめます。

```sh
sh check-mutations.sh
```

このスクリプトは一時フォルダに写しを作って検査し、元のファイルは変えません。六つの写しがすべて拒否されれば終了状態は0です。

`rocq compile` は同じフォルダに `.vo` などを、`agda` は `.agdai` を書き出します。Agda は以前の検査の記録があると何も出力しないので、`--ignore-interfaces` を付けます。2026-11-13 に Lean 4.35.0、Rocq 9.3.0、Agda 2.8.0.2 で、三つとも受理されることを確かめました。

## 保証の範囲

検査したのは、ここに書いた自由な構成子型についての上の定理です。整数以降の一般法則、JavaScript の厳密算術の実装、λ計算インタプリタ、Fε の法則は、この移植の対象ではありません。
