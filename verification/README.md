# 検証資料 — 論文 v1.5.7 / インタプリタ v8.0.1

このフォルダでは、λ変換、型付き等式、厳密算術、生成ラベルの有限応答、レジスタ遷移と仮定付き式変形の証拠を区別します。いずれも有限データですが、採用する規則と保証範囲が異なります。ZF・ZFCや固定したPA系を証拠の内部前提へ加えません。

v1.5.5で追加した `NatForm` は、共通構文Uの有限木が自然数表示の形かを検査し、真偽値を返す再帰判定です。停止と判定の正しさの根拠は本文§2.8の手書き証明に置きます。正根拡張Tの代数法則と順序の根拠は本文§8.10と[有限対による型Tの拡張例](../research/extension-example-v1.5.7.md)の手書き証明に置きます。基本記号の構造例、符号化と復号、選んだ有限入力の実行・算術照合は、これらの一般証明の機械検証とは別に扱います。T専用の一般算術APIや、新しい汎用証明検査器を追加したとはしません。

処理履歴の名称は「計算証跡」とします。証拠ファイル名の版は論文版に合わせますが、互換な形式識別子は変更しません。例えば `generator-extensions-v1.5.4` は検査核と対応する形式名として保持します。既存の保存形式を保持し、追加の証拠は独立した形式名と検査器で扱います。詳細な検査件数と成功・失敗は [verification-report.json](verification-report.json) と [evidence-report.json](evidence-report.json) に記録します。

## 再現手順

Node.js 20 以降の標準機能を使います。外部パッケージのインストールは不要です。配布フォルダのルート、または作業フォルダのルートで実行します。

```sh
node scripts/verify.mjs
node scripts/generate-evidence.mjs
node scripts/generate-concepts.mjs --check
node scripts/generate-f-only.mjs --check
node scripts/check-english-translation.mjs --check
node scripts/generate-english-appendix.mjs --check
```

一般等式の証拠だけを検査する場合：

```sh
node verification/equational-checker.mjs verification/certificates/nat-and-paths.json
```

作業フォルダではテスト結果をレポートに保存します。`MANIFEST.json` がある配布フォルダで再実行するときは、配布済みの実行記録とチェックサムを保つため、テスト結果を画面に出力し、記録済みレポートは書き換えません。

λ の証跡ファイルは [インタプリタ](../interpreter/lambda_interpreter_v8.0.1.html) の「JSON を読み込み検証」でも検査できます。

既存の小核を個別に検査する場合は、次を実行できます。

```sh
node verification/lambda-arithmetic-tests.mjs
node verification/generator-extensions-tests.mjs
node verification/model-extensions-tests.mjs
```

## 信頼する規則と限界

`equational-checker.mjs` は、Nat の `Z/S`、Seq の `Nil/Cons`、各演算の型、加法・乗法・連結の計6本の再帰定義、等式の合同・対称・推移、既証明の全称等式の代入、Nat / Seq の構造帰納を規則として持ちます。帰納仮定はその帰納段の変数に固定し、任意の項へ一般化しません。追加の未検証公理を証拠ファイルから読み込む機能はありません。

これは任意の λ 項についての等式判定器ではありません。Church 表現との対応は論文中の別の帰納的説明に依存します。整数・有理数・M の全法則、順序、解析の全称的誤差定理、射の合成可能性は、この16個の機械証明に含まれません。列連結の一般法則と、端点付きの適切な履歴の圏としての証明を区別します。

`applications.mjs` の有理数計算は BigInt の有限整数演算、gcd による既約化、正の分母を用います。ゼロ除算を拒否します。規則の入力、出力、前提、結論への接続を再検査します。生成器と検査器は有理算術とマクロ規則の実装を共有するので、別実装による独立な算術検証や実装全体の形式証明までを意味しません。根拠となる一般的な不変量・誤差評価は [応用ノート](../research/applications-v1.5.7.md) に記載しています。

論文のアルゴリズムには任意の有限精度を入力できますが、配布コードにはメモリ・時間を考慮した資源上限があります。上限到達は数学的な発散を意味しません。

### λ整数・分数算術

v8.0.1の全66内蔵定義のうち、34定義は整数と分数の接続のために追加しました。整数は自然数の符号0/1と大きさの対です。旧稿の自然数二つの差との変換を提供しますが、今回の整数表示は変更しません。

λ計算の分数は正の非零分母を持つ未約分の補助型QRepであり、本文の既約なQとは形成条件が異なります。QRepの四則と等値は、本文の有理数へ正規化した値との対応を手書きで証明しています。λによるgcdや既約化は含めず、その処理をホスト算術に置き換えてβの一手と称することもしません。`QMake`、逆数、除算は成功と零分母エラーを区別します。いずれも指定の入力型に対する定義であり、任意のλ項の型を認定する検査ではありません。

v8.0.1の戦略 `leftmost-outermost-interleaved` はδとβを合わせて左端最外の位置を選びます。旧v8.0.0の `leftmost-outermost` 記録は旧来のδ優先戦略で再検査します。証跡の版と戦略の対応も検査対象です。詳しい入力条件と信頼する共通実装は [λ算術資料](../research/lambda-arithmetic-v1.5.7.md) と [インタプリタ仕様](../interpreter/README.md) に示します。

### 区間生成ラベルの拡張

`generator-extensions.mjs` は、有限データで指定した既知の規則を扱います。Newton法、二分法との区間の交わり、単調な交代和、誤差率を持つ数列の有限区間化、ラベルの加算・乗算・非零分離を証拠とする逆数について、要求と途中の有限算術を記録します。差は負一倍との加算、除算は逆数との乗算で表せます。

検査器は証跡の全体を再構成して比較しますが、生成側と有理算術・規則の実装を共有します。成功は指定要求における局所計算の再検査であり、任意のプログラムの停止性や全要求の誤差契約を形式証明したことにはなりません。一般保証と応答整合は [応用研究ノート](../research/applications-v1.5.7.md) の手書き証明に分けて記載します。

区間生成ラベルはFεや正根拡張Tと別の型です。計算前に使用する型を固定し、Newton法や二分法は有理区間の応答を求める場合に選びます。数の内部構成のすべてに生成器を付ける条件は置きません。有理精度で幅を小さくする証拠から、Fεの任意の正元を許容誤差とする保証を結論しません。応答整合の関係を使って全ラベルを係数体へ商にする処理も、この実装にはありません。

### レジスタ計算と条件付きの等式証跡

`model-extensions.mjs` のレジスタ検査器は実行器を呼び出さず、保存された隣接状態について命令位置と全レジスタの更新を確認します。命令列、初期入力、出力レジスタ、終了命令への到達も検査します。2+3の例は三レジスタ・六つの命令を使う十四遷移です。初期値や出力を別の正しい証跡へすり替えても、指定された主張との照合で拒否します。

短い等式証跡では、加法群の法則の下で `(c+u)+(-u)=c` を3手、境界と二つの逆関係を仮定して `g=h` を5手で導きます。規則・代入・位置・向き・射の境界を検査します。検査器側に固定した構造法則を、Fεの体法則そのものの機械証明とは呼びません。Fεへの適用の根拠は本文の構成と手書き証明です。

これらと既存のNat/Seqの16命題は別の規則系です。一般の計算モデルの翻訳には入力、状態の対応、有限段の模倣、終了と復号の保存が必要であり、本版はその一般的な翻訳器を提供しません。[証跡拡張資料](../research/trace-extensions-v1.5.7.md) に条件付き保存定理と、手書き証明・実装検査の範囲を記載します。

### Fε の演算と証拠

`formal-field.mjs` は有理係数を低い次数から並べた有限列を用います。これが本版のMです。`field(numerator,denominator)` が多項式gcdで約分し、分母の最高次係数を一にします。分母零は形成時に拒否します。`fieldAdd/Sub/Mul/Div`、`fieldEq`、`fieldCmp`、`embedL(k,a)`、`standardPart` を提供します。旧API名 `embedM` はLの一次表示をFへ移す `embedL` の互換名として保持します。順序比較は最小非零次数の係数を**分子・分母の両方**で調べます。`standardPart` は零と、分子の最小次数が分母以上の元だけを受理します。

`generateFieldCertificate(operation,input)` は `normalize`、`add/sub/mul/div`、`eq`、`compare`、`standardPart`、`embedM`、`polyDivmod`、`polyGcd` の有限計算を記録します。二項演算の入力は二つの値の配列、値の表示は `{numerator:[係数],denominator:[係数]}` です。係数は `applications.mjs` の `q` で構成します。生成した証拠は JSON に保存し、`verifyFieldCertificate` で再検査できます。

証拠は入力と計算の二つの複合規則を持ち、計算の内訳には Euclid の各商・余り、gcd除去、モニック化、または比較に使う最低次係数を含めます。検査側はその有限計算を再実行して全内訳と結論を照合します。同じ有理算術・多項式処理を共有するため、その実装は信頼する基盤です。体公理の全称的な証明は論文第8節の手書き証明であり、有限例のテスト結果とは区別します。このモデルの実装は `qlim` の最終的な解釈を決定するものではありません。

## 基本記号による表示

`concept-codec.mjs` は `f()`、`f(t)`、`(t,u)` を厳密に解析・印刷し、自然数・整数・有理数・多項式M・F・複素数・四元数・文字列・有限JSONの型別符号化と復号を提供します。数の正規化と複素行列の制約も検査します。四元数の全算術APIを実装したものではありません。

`scripts/generate-concepts.mjs` は [構成規則](../research/concept-symbols-v1.5.7.md) に従い、[完全展開例](../research/concept-examples-v1.5.7.md) と `concept-symbols-v1.5.7/*.f` を生成します。`--check` では保存内容を変更せず再検査します。全66内蔵λ定義を復号して元項とのα同値を確認し、保存済み証拠束を復号してそれぞれの意味検査器へ渡します。v1.5.5のNatFormとTの構造例・有限算術照合も、この生成資料の検査範囲に記録します。

証拠のJSON外装を基本記号へ変換しても、その証明規則がλのβ規則に変わるわけではありません。説明用の一般論理構文や証明節点の形については、構文の保存と、汎用論理の意味検査を区別しています。

### fだけの付録

`f-only-codec.mjs` は同じ構文木を、零子 `f()`、一子 `f(t)`、二子 `f(tu)` の表記へ一意に変換・復元します。`printFOnly`、`parseFOnly`、`convertToFOnly`、`convertFromFOnly` を提供します。カンマや独立した組の括弧を受理せず、根が二つある入力や子が三つある入力も拒否します。型の意味や演算規則は変更しません。

`generate-f-only.mjs` は、版別manifestの構造例と証拠束を変換し、本文全文を導入部と各章に分けて文字列として保存します。各片を復元して連結した結果が現在の本文に完全一致すること、収録した実装ソースが復元できることも確認します。証拠束は構造例の一覧に含めて記録します。全文保存の成功を、文章中の全推論の機械検証とは呼びません。各例・保存元・検査結果の最新一覧は版別のmanifestとreportに記録します。

## 記録

実行した検査群、保存済み証拠の種類と件数、成否は、以下のレポートを参照してください。Nat/Seqの16一般等式、仮定付き式変形、個別の有限計算、実装テストの件数は、それぞれの保証範囲を保って記録します。これらを合算して一般数学定理の数とはしません。

### 関係子ラベルの導入と有限例

v1.5.6で導入した規則は、bを保持する生成記録と、bの符号から関係子ラベルを導入する有限分岐を区別します。共通部分列の有限添字、正負零の導入、Lの関係子個数を保つ加算、Phiの非加法性、不正入力と虚偽結果の拒否は `scripts/generate-concepts.mjs` の個別検査です。f表記の復号後に記録した値を再計算し、入力ごとの証拠を版別reportに保存します。

共通部分列の全称命題、導入の一般保証、有理精度と微小方向の一般的な誤差評価は手書き証明です。有限例が成功したことを、それらの一般定理の機械形式化とはしません。既存の有理区間・二分法・Newton法の実行規則は保持し、HTMLに関係子導入の新しい汎用APIを追加したとはしません。詳しくは[関係子ラベルの導入ノート](../research/label-design-v1.5.7.md)を参照してください。

## 循環桁の解釈と等比生成族H（v1.5.7）

付録Aの循環桁記録は、小数の桁を記述する有限データです。有理評価・下側生成・上側生成は明示的に指定します。`1/3` は厳密な有理数として検査し、ラベルの整数成分へ暗黙に置き換えません。`scripts/generate-concepts.mjs` はHの有理パラメータと有限応答、符号による導入、ラベル加算、メンガーの有限段の計算を、収録した入力で再検査します。

全入力の誤差境界や停止の一般保証は手書き証明です。本文で採用する直観主義の推論方針は、新しい汎用論理検査器や、型なしλ項の全実行を論理的証明にする規則を追加したことを意味しません。構文を保存・復号すること、個別の算術を検査すること、一般の証明データを検査することを区別します。
